# The run record

`sources/README.md` carries the conclusions. These two files carry the order the
findings landed in, which is worth keeping for one reason.

The scoreboard was written incrementally, one family at a time, before the answer
was known. Read top to bottom it shows `rollout` recorded as a structural hole on
two independent families, and then overturned by a targeted pass that found it was
the densest shape measured. That reversal is the strongest evidence in the whole
run that the surveys were reporting rather than confirming, and a synthesis
written afterwards cannot show it.

`PLAN.md` is how the run was ordered, kept so the shape can be repeated.
