# Returns desk

A small library has three books. At any moment each book is on the shelf,
out on loan, or on the returns desk. A borrower takes a book from the
shelf. A borrower brings a book back and leaves it on the desk. The
librarian takes a book off the desk and puts it back on the shelf.

Write the specification from an empty file. Say what the state can be.
State the rule that a book is never out on loan and on the desk at the
same time.

Check it and note the count. A colleague who wrote the same library found
a different number of distinct states, and both of you are right. Say what
the two of you chose differently, and which choice made the rule harder to
break.
