# Solution: The Laytime Statement

## Spec and CFG

### Laytime.tla
```
---------------------------- MODULE Laytime ----------------------------
EXTENDS Naturals

CONSTANT Allowance, Limit

VARIABLES noticeTendered, laytimeLeft, demurrage, finished

Observe == [
  noticeTendered |-> noticeTendered,
  laytimeLeft |-> laytimeLeft,
  demurrage |-> demurrage,
  finished |-> finished
]

Init ==
  /\ noticeTendered = FALSE
  /\ laytimeLeft = Allowance
  /\ demurrage = 0
  /\ finished = FALSE

TenderNotice ==
  /\ noticeTendered = FALSE
  /\ noticeTendered' = TRUE
  /\ UNCHANGED <<laytimeLeft, demurrage, finished>>

LogPeriod ==
  /\ noticeTendered = TRUE
  /\ finished = FALSE
  /\ laytimeLeft > 0
  /\ laytimeLeft' = laytimeLeft - 1
  /\ UNCHANGED <<noticeTendered, demurrage, finished>>

LogDemurrage ==
  /\ noticeTendered = TRUE
  /\ finished = FALSE
  /\ laytimeLeft = 0
  /\ demurrage < Limit
  /\ demurrage' = demurrage + 1
  /\ UNCHANGED <<noticeTendered, laytimeLeft, finished>>

Finish ==
  /\ noticeTendered = TRUE
  /\ finished = FALSE
  /\ finished' = TRUE
  /\ UNCHANGED <<noticeTendered, laytimeLeft, demurrage>>

Next ==
  \/ TenderNotice \/ LogPeriod \/ LogDemurrage \/ Finish

Spec == Init /\ [][Next]_<<noticeTendered, laytimeLeft, demurrage, finished>>

Req1Action ==
  /\ (noticeTendered = FALSE =>
      (laytimeLeft' = laytimeLeft /\ demurrage' = demurrage /\ finished' = finished))
  /\ (finished' = TRUE =>
      (laytimeLeft' = laytimeLeft /\ demurrage' = demurrage /\ noticeTendered' = noticeTendered))

Req1 == [][Req1Action]_<<noticeTendered, laytimeLeft, demurrage, finished>>

OneMoveAction ==
  /\ (laytimeLeft' = laytimeLeft \/ laytimeLeft' = laytimeLeft - 1)
  /\ (demurrage' = demurrage \/ demurrage' = demurrage + 1)
  /\ ~(laytimeLeft' < laytimeLeft /\ demurrage' > demurrage)

Req2 == [][OneMoveAction]_<<laytimeLeft, demurrage>>

Req3 == (demurrage > 0 => laytimeLeft = 0)
=============================================================================
```

### Laytime.cfg
```

  Req3
```

**Pair 2 (Req2: One period, one move)**
- Allowed (4-state sequence): Produced by Init→TenderNotice→LogPeriod→LogPeriod ✓

## Mechanism Recognition

Laytime is a lease-expiration system with a two-phase payment model: first, an allowance countdown; then, penalty accrual. This is a common pattern in time-based billing (maritime chartering, construction projects, equipment rentals).
