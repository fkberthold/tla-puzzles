# Herbarium, seat p1. 1. Spec and cfg, verbatim (Herbarium.tla, Herbarium.cfg)
```tla
---- MODULE Herbarium ----
EXTENDS Naturals, FiniteSets
CONSTANTS Sheets, Botanists, Names, Handling, NONE
VARIABLES slips, consulted, reading, accepted, doubted
vars == <<slips, consulted, reading, accepted, doubted>>
HandlingFn == [s \in Sheets |-> IF s = 1 THEN 2 ELSE 1]
Observe == [slips |-> slips, consulted |-> consulted, reading |-> reading, accepted |-> accepted, doubted |-> doubted]
TopName(S) == (CHOOSE x \in S : \A y \in S : y.stamp <= x.stamp).name
Init == /\ slips = [s \in Sheets |-> {}] /\ consulted = [s \in Sheets |-> 0] /\ doubted = [s \in Sheets |-> FALSE]
        /\ reading = [b \in Botanists |-> [s \in Sheets |-> NONE]] /\ accepted = [s \in Sheets |-> NONE]
Consult(b, s) == /\ consulted[s] < Handling[s] /\ consulted' = [consulted EXCEPT ![s] = @ + 1]
                 /\ reading' = [reading EXCEPT ![b][s] = consulted[s] + 1] /\ UNCHANGED <<slips, accepted, doubted>>
File(b, s, n) == /\ reading[b][s] # NONE
                 /\ slips' = [slips EXCEPT ![s] = @ \cup {[name |-> n, stamp |-> reading[b][s]]}]
                 /\ accepted' = [accepted EXCEPT ![s] = TopName(slips'[s])]
                 /\ reading' = [reading EXCEPT ![b][s] = NONE] /\ doubted' = [doubted EXCEPT ![s] = FALSE]
                 /\ UNCHANGED consulted
Doubt(b, s) == /\ reading[b][s] # NONE /\ ~doubted[s] /\ doubted' = [doubted EXCEPT ![s] = TRUE]
               /\ UNCHANGED <<slips, consulted, reading, accepted>>
Next == \E b \in Botanists, s \in Sheets : Consult(b, s) \/ Doubt(b, s) \/ \E n \in Names : File(b, s, n)
Fairness == \A b \in Botanists, s \in Sheets : WF_vars(\E n \in Names : File(b, s, n))
Spec == Init /\ [][Next]_vars /\ Fairness

WellFormed == \A s \in Sheets :
    /\ \A x \in Observe.slips[s] : x.name \in Names /\ x.stamp \in 1..Observe.consulted[s]
    /\ \A x, y \in Observe.slips[s] : x.stamp = y.stamp => x = y
    /\ \A b \in Botanists : Observe.reading[b][s] # NONE => Observe.reading[b][s] \in 1..Observe.consulted[s]
    /\ Observe.consulted[s] <= Handling[s]
AcceptedIsTop == \A s \in Sheets :
    IF Observe.slips[s] = {} THEN Observe.accepted[s] = NONE
    ELSE \E x \in Observe.slips[s] : Observe.accepted[s] = x.name /\ \A y \in Observe.slips[s] : y.stamp <= x.stamp
RecordGrows == [][\A s \in Sheets :
    /\ Observe.slips[s] \subseteq Observe'.slips[s] /\ Observe'.consulted[s] >= Observe.consulted[s]
    /\ Observe'.consulted[s] > Observe.consulted[s] =>
         /\ Observe'.consulted[s] = Observe.consulted[s] + 1
         /\ \E b \in Botanists : /\ Observe'.reading[b][s] = Observe'.consulted[s]
                                 /\ \A c \in Botanists \ {b} : Observe'.reading[c][s] # Observe'.consulted[s]
    /\ \A b \in Botanists : (Observe'.reading[b][s] # Observe.reading[b][s] /\ Observe'.reading[b][s] # NONE)
         => Observe'.reading[b][s] = Observe'.consulted[s] /\ Observe'.consulted[s] > Observe.consulted[s]
  ]_(<<Observe.slips, Observe.consulted, Observe.reading>>)
SlipFromConsultation == [][\A s \in Sheets :
    /\ Observe'.slips[s] \ Observe.slips[s] # {} =>
         /\ Cardinality(Observe'.slips[s] \ Observe.slips[s]) = 1
         /\ \E b \in Botanists : /\ Observe.reading[b][s] # NONE /\ Observe'.reading[b][s] = NONE
                                 /\ \A x \in Observe'.slips[s] \ Observe.slips[s] : x.stamp <= Observe.reading[b][s]
    /\ \A b \in Botanists : (Observe.reading[b][s] # NONE /\ Observe'.reading[b][s] = NONE)
         => Observe'.slips[s] \ Observe.slips[s] # {}
  ]_Observe
DoubtClearsOnlyOnFiling ==
    [][\A s \in Sheets :
          (/\ Observe.doubted[s] = TRUE
           /\ Observe'.doubted[s] = FALSE)
              => Observe'.slips[s] \ Observe.slips[s] # {}]_(Observe.slips)
EventuallyAnswered ==
    /\ \A b \in Botanists, s \in Sheets : Observe.reading[b][s] # NONE ~> Observe.reading[b][s] = NONE
    /\ \A s \in Sheets : Observe.doubted[s] ~> ~Observe.doubted[s]
Opening == \A s \in Sheets : /\ Observe.slips[s] = {} /\ Observe.consulted[s] = 0 /\ Observe.accepted[s] = NONE
                             /\ ~Observe.doubted[s] /\ \A b \in Botanists : Observe.reading[b][s] = NONE
====
```

INVARIANTS WellFormed  AcceptedIsTop
PROPERTIES RecordGrows  SlipFromConsultation  DoubtClearsOnlyOnFiling  EventuallyAnswered  Opening
