## Properties (verbatim from AssayOffice.tla)

```tla
Inv1 == \A w \in Wares:
    /\ (Observe.marked[w] => Observe.finding[w] = "atStandard")
    /\ (Observe.defaced[w] => Observe.finding[w] = "substandard")

Prop2 == [][
    \A w \in Wares:
        /\ (Observe.finding[w] = "none" \/ Observe.finding[w] = Observe'.finding[w])
        /\ (Observe.marked[w] => Observe'.marked[w])
        /\ (Observe.defaced[w] => Observe'.defaced[w])
]_Observe

Prop3 == \A w \in Wares: (Observe.finding[w] = "substandard") => <>(Observe.defaced[w])
```
