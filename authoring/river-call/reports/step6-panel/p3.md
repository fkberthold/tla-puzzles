# River Call - Blind Panel Solution (Seat p3)

## 1. Spec and Configuration

**RiverCall.tla:**
- Models water distribution system with owners, headgates, decrees, and calls
- State: diverted (function owner->amount) and calling (function owner->boolean)
- Owners can change their gate settings (must obey flow constraint and call blocking rule)
- Owners can place/remove calls when short

**test.cfg:** Flow=3, all owners decreed 2 units
**RiverCall.cfg:** Flow=6, all owners decreed 2 units

## 2. TLC Results on Test Configuration

**Flow=3:** 721 states generated, 136 distinct states, depth 9. All requirements pass.
**Flow=6:** 163 states generated, 27 distinct states, depth 4. All requirements pass.

## 3. Trace Verification

**Pair 1 (Flow violation):**
- Allowed: 1→2, then 2→1 (total=3 ≤ 3). Both allowed.
- Forbidden: 1→2, 2→2 (total=4 > 3). TheFlowHolds rejects it.

**Pair 2 (Call blocking violation):**
- Allowed: 1→2, 2 calls (short: 1 available from 3), 2→1 works (junior respects).
- Forbidden: Same sequence but 3→1 while 2 calling. NobodyOpensAgainstACall rejects it.

**Pair 3 (Dishonest call):**
- Allowed: 1→2, 2 calls (available=1, need 2, short).
- Forbidden: All shut, 1 calls (available=3, need 2, not short). ACallIsHonest rejects it.
